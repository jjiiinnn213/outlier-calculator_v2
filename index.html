1. 데이터 입력 및 이상치 계산

샘플명, 생산일자, HPH 값을 입력하고 Size(nm)와 PI 측정값을 직접 입력하거나 Excel/CSV에서 불러옵니다. HPH 변수명과 단위는 바꿀 수 있습니다. Z-Score, IQR, MAD 임계값을 확인한 뒤 계산합니다.

데이터 분포 시각화에서는 원본과 각 방법으로 이상치를 제거한 뒤의 분포를 하나씩 또는 함께 선택할 수 있습니다.

2. 결과 CSV 다운로드 및 재사용

결과 CSV에는 원본 측정값과 방법별 통계, 남은 데이터, 제외된 데이터가 들어갑니다. 결과 CSV를 다시 열면 원본 구간만 불러옵니다. 원본 구간이 없는 이전 결과 CSV는 원본 복원에 사용할 수 없습니다.

파일명 예: outlier_results_6 pass_20261027_6.csv (샘플명_생산일자_HPH 값).

3. 데이터셋 관리 및 비교

데이터셋은 원본을 보관합니다. 비교 시 원본 또는 Z-Score, IQR, MAD를 선택해 현재 임계값으로 비교할 수 있습니다. 데이터 관리에서 검색, 원본 확인 및 편집, 백업, 가져오기 미리보기를 사용할 수 있습니다.

4. 실험군·대조군과 상관관계

샘플 정보와 평균을 직접 입력하거나 저장 데이터셋과 이상치 제거법을 선택해 Size·PI 평균을 불러올 수 있습니다. 사용자 정의 변수명과 단위를 지정하고 해당 측정값을 입력하세요. 단위 이름을 바꿔도 값은 자동 환산되지 않습니다.

상관관계는 사용자 정의 변수와 입도를 중심으로 표시합니다. 하위 항목에서 사용자 정의 변수–입도, 입도–PI, PI–사용자 정의 변수를 볼 수 있습니다. 그래프 설정과 이미지 저장도 사용할 수 있습니다.

5. 저장과 백업

데이터는 현재 브라우저에 저장되며 다른 기기와 자동으로 공유되지 않습니다. 브라우저를 바꾸거나 사이트 데이터를 지우기 전에 데이터 관리에서 ZIP으로 백업하세요.

처음 분석할 때 따라 하기
  1. 예를 들어 샘플명에 ‘6 pass’, 생산일자에 ‘2026-10-27’, HPH 값에 ‘6’을 입력합니다.
  2. 측정 한 건마다 한 행에 Size(nm)와 PI를 입력합니다. 두 값이 모두 유효한 행이 이상치 분석에 사용됩니다. 미측정값은 빈칸으로 둡니다.
  3. 임계값을 확인하고 이상치를 계산한 뒤, 방법별 남은 개수와 제외된 행을 확인합니다.
  4. 분포에서 원본과 제거 후 결과를 함께 선택해 차이를 확인합니다. 같은 측정 행이 여러 분포에 중복되므로 회귀는 분포 하나만 선택해 실행합니다.
  5. 시료를 다시 분석할 예정이면 데이터셋으로 저장합니다. 보고용 결과는 CSV 또는 Excel로 내려받습니다.
저장 데이터 찾기·수정·복원
  • 데이터 관리에서 샘플명, 생산일, HPH 값, 그룹으로 검색합니다. 여러 항목을 선택하면 원본을 각각 확인하거나 함께 백업할 수 있습니다.
  • 원본 편집을 누르면 위쪽 입력 표에서 수정할 수 있습니다. 원본 변경 저장으로 확정하면 이전 값이 수정 이력에 남습니다.
  • PC나 브라우저를 옮길 때는 전체 ZIP을 저장합니다. CSV는 시료별 원본과 결과를 담고, 전체 ZIP에는 저장 샘플·설정·이력도 포함됩니다.
  • 새 환경에서 ZIP을 가져오고 미리보기의 정상·오류·중복 항목을 확인합니다. 기존 기록을 교체할 의도가 있을 때만 덮어쓰기를 선택합니다. 가져온 뒤 시료 ID와 행 수, 주요 측정값을 대조합니다.
샘플 선택·단독 분석·그래프 저장
  • 저장 데이터셋에서 평균을 불러올 때는 위쪽의 현재 임계값을 사용합니다. D0·D1 및 전단속도별 점도 반복값은 쉼표로 구분해 입력할 수 있습니다. 한 값만 있으면 표준편차와 오차막대를 계산할 수 없습니다.
  • 저장 샘플 목록에서 분석에 포함할 시료를 선택합니다. 단독 분석은 저장 샘플이나 원본 데이터셋을 원천으로 선택한 뒤 X축, 측정 항목, 그래프 유형을 정합니다.
  • 그래프 아래 설정을 펼쳐 제목, 축, 단위, 범례와 계열 모양을 조절하고 적용합니다. 단위 이름만 변경하면 값은 그대로 표시되므로 수치 환산이 필요할 때는 원단위와 출력 단위를 지정합니다.
  • 회귀선과 r, R², p는 별도로 표시할 수 있습니다. p 계산에는 유효한 수치 쌍이 최소 3개 필요합니다. 상관관계만으로 인과관계를 판단할 수 없습니다.
  • 각 그래프에서 PNG 또는 SVG를 저장합니다. 여러 그래프는 페이지 아래 이미지 일괄 저장에서 목록을 갱신한 뒤 선택해 ZIP으로 받습니다.
